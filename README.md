### Open source

- [**uk-mot-history**](https://github.com/behoss/uk-mot-history): Client for the official DVSA MOT History API: tests, mileage and defects by registration or VIN. Powers [GetFreeCarCheck](https://getfreecarcheck.co.uk).
- [**geo-kit**](https://github.com/behoss/geo-kit): Make a Next.js site quotable by ChatGPT and AI search: JSON-LD builders, llms.txt, AI-crawler rules and an audit CLI. Powers [Softgen](https://softgen.co.uk).
- [**esim-coverage**](https://github.com/behoss/esim-coverage): Which mobile networks a travel eSIM connects to, country by country, in JSON and CSV. Powers [eSIMology](https://esimology.com).
- [**skincare-ingredients**](https://github.com/behoss/skincare-ingredients): INCI cosmetic ingredient names decoded in plain English, with free-from flags. Powers [Beauty Comparison](https://beautycomparison.com).
- [**beauty-label-audit-2026**](https://github.com/behoss/beauty-label-audit-2026): 1,641 cosmetic ingredient lists decoded against 12 ingredient families. Powers [Beauty Comparison](https://beautycomparison.com).
- [**neo4j-graphrag**](https://github.com/behoss/neo4j-graphrag): Knowledge-graph RAG on Neo4j and Gemini, with entity resolution and graph-plus-vector search. Powers [Softgen](https://softgen.co.uk).
- [**computer-use**](https://github.com/behoss/computer-use): A macOS desktop agent on Gemini's Computer Use API: give it a goal and an app, it sees the screen and acts. Powers [Softgen](https://softgen.co.uk).
